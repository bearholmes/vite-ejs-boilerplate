Quick Start

Template Structure

Add HTML/EJS to `src/pages` and it will automatically appear in the route index.

Write JSON meta at the top of the template.

Style System

Basic styles and page-specific SCSS are configured in `src/assets/styles`. Extend with your own variables and utilities.

SCSS is automatically bundled by Vite.

Common Layouts

Manage navigation in one place via `src/templates/partials` header/footer.

Edit brand/links to reflect across all pages.
Next Steps
  • New Page: Create `src/pages/folder/page.ejs` and add `<%# { "group" : "..." , "depth1" : "..." } #%>` meta.
  • Styles: Add corresponding SCSS to `src/assets/styles/pages/` and import in `style.scss` if needed.
  • Build: Run `npm run build` and check the `dist/` result.
